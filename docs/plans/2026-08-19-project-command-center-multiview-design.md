# Agentic Project OS 多视图原型设计

## 目标

为同时推进多个项目的独立全栈开发者提供一个 ADHD 友好的 Agent 原生项目管理系统。界面需要把注意力、时间、里程碑、工作树、Agent 活动、想法和 Git 证据放进同一套关系系统，减少在单一项目上过度投入导致其他项目失速的问题。

## 方案选择

采用“单一应用外壳 + 多视图状态 + 共享示例数据”的高保真前端原型。

- 相比一组静态页面，它可以演示从 Inbox 到项目、从里程碑到任务、从工作树到 Git 证据的真实跳转。
- 相比立即接入完整后端，它能先验证信息架构、视觉密度、ADHD 时间引导和 Agent 可读写模型。
- GitHub/Gitea 导入保留为新建项目子流程，现有高保真连接页面继续复用。

## 信息架构

### 全局层

- 今天：当前焦点、时间盒、Next/Later、并行 Agent、失速项目和稳定产出提示。
- 总 Inbox：语音/文本捕获、待整理想法、归属项目和转换动作。
- 项目：项目组合、当前里程碑、健康度、投入时间、最近活动和阻塞。
- 时间：日/周时间轴、项目预算、实际投入、注意力偏移和重新平衡建议。
- 知识图谱：由项目、里程碑、任务、想法、工作树、提交和日志双向链接形成的 3D 图谱。

### 项目层

- 总览、里程碑、工作树、任务、项目 Inbox、脑图、日志、设置。白板于 2026-08-20 暂缓进入首版界面。
- 项目头部持续显示当前里程碑、代码托管来源、同步状态和 Agent 状态。
- 脑图使用 React Flow；知识图谱使用 react-force-graph-3d。

## 共享实体与关系

- Project → Milestone → Plan → Task。
- Project → Worktree → Agent / Branch / Commit / Output / Blocker。
- Idea 可通过 `@项目`、`@工作树`、`@里程碑` 建立双向链接，并可转成 Milestone、Plan 或 Task。
- Activity/Log 记录用户、Agent、GitHub/Gitea 和自动化产生的事件。
- TimeBlock 连接 Project、Task 与实际投入，用于发现项目失速和时间偏移。

## 核心交互

- 主导航切换全局视图，项目卡进入项目空间，项目标签切换内部视图。
- 快速记录支持文本和语音模拟；Inbox 条目可以整理进项目。
- 今天视图支持完成当前任务、开始/暂停专注时间盒和切换 Next 任务。
- 工作树视图显示负责人/Agent、状态、最近活动、产出和阻塞。
- 脑图可缩放、拖动并显示双向链接。
- 3D 图谱支持旋转、缩放、点击节点聚焦和类型筛选。

## 原型边界

本轮实现真实前端交互与跨视图状态，但使用本地示例数据。Gitea/GitHub API、数据库持久化、MCP/CLI 服务、语音转写 API 和真实 Agent 调度留在后端集成阶段。

## 验收

- 所有核心视图可从导航到达，没有静态死页。
- 1440 × 1024 桌面视口保持统一设计语言，并检查 1180、980、720 宽度。
- 构建和 Sites worker 测试通过。
- 浏览器控制台无错误/警告，核心导航和关键动作可操作。
- 按设计系统参考与实现截图完成并排视觉 QA，`design-qa.md` 结果为 `passed`。
